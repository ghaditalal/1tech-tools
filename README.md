# 1Tech Tools Directory

**A directory of useful tech tools for programmers and tech students — in Arabic.**

The site gathers popular tools like GitHub, VS Code, Postman and Wireshark, with a short description of each tool, what it's used for, and a link to its official website.

🔗 **Live site:** [ghaditalal.github.io/1tech-tools](https://ghaditalal.github.io/1tech-tools/)

---

## Features

- **18 tools** across 5 categories: Programming & Development, Version Control, Cybersecurity, Networks & Systems, Design & Productivity
- **A card for each tool** with a short description, three common uses, difficulty level (Beginner / Intermediate / Advanced), pricing, and a link to the official site
- **Instant search** in Arabic and English that handles Arabic spelling variations (e.g. اداة finds أداة)
- **Category filters** with one click
- **Favorites**: tap the heart to save tools; they stay saved in your browser
- **Suggest a tool**: jumps to a random tool and highlights it
- **Light and dark mode** based on your device settings
- **Responsive** on phones, tablets and desktops
- **Right-to-left (RTL)** layout for Arabic

## Tools Included

| Category | Tools |
|---|---|
| Programming & Development | VS Code · Postman · DBeaver · Jupyter Notebook · Chrome DevTools · Replit |
| Version Control | Git · GitHub |
| Cybersecurity | Wireshark · Nmap · Burp Suite · Kali Linux |
| Networks & Systems | Cisco Packet Tracer · VirtualBox · Docker |
| Design & Productivity | Figma · Notion · Jira |

## Built With

- **HTML** for the page structure
- **CSS** for styling, using CSS variables, dark mode, and glass and glow effects
- **JavaScript** for rendering cards, search, filters and favorites (no external libraries)
- **Alexandria** and **IBM Plex Sans Arabic** fonts from Google Fonts

## File Structure

```
1tech-tools/
```

## Run Locally

Download the files into one folder and open `index.html` in your browser. No installation needed.
